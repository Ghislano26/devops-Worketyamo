# Checklist des compétences — Module 01 : Fondamentaux

Une checklist « admin sys » à cocher au fil du module, comme dans le Linux Upskill Challenge. **Coche une case seulement quand tu sais le faire sans regarder le cours**, sur ton serveur. Chaque compétence renvoie vers le cours ou l'atelier qui la travaille.

> 📌 **À retenir** : une compétence n'est acquise que lorsque tu peux la **refaire de mémoire** dans une VM restaurée. Reviens sur cette liste dans une semaine : quelles cases sais-tu encore cocher ?

## Checklist des compétences — Module 01

- [ ] Je sais me connecter en SSH à mon serveur depuis ma machine hôte — *[SERVEUR.md](SERVEUR.md), [module 00](../00-installation-ubuntu-vm/checklist-post-installation.md)*

- [ ] Je sais lire l'arborescence Linux (`/etc`, `/var`, `/home`, `/proc`…) et dire à quoi sert chaque dossier — *[Cours 02](cours/02-systeme-fichiers.md)*
- [ ] Je sais naviguer avec `cd`, `pwd`, `ls -la`, `tree` sans interface graphique — *[Atelier 01](ateliers/atelier-01-navigation.md), [Killercoda 01](ateliers-killercoda/atelier-01-navigation-killercoda/)*

- [ ] Je sais lire et écrire des permissions (`rwx`, octal) avec `chmod` et `chown` — *[Cours 04](cours/04-utilisateurs-permissions.md), [Atelier 03](ateliers/atelier-03-permissions.md), [Killercoda 03](ateliers-killercoda/atelier-03-permissions-killercoda/)*
