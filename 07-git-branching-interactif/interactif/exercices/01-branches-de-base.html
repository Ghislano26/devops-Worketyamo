1. Branches de base : créer, se déplacer, committer

Une branche n'est qu'un pointeur sur un commit. Créez-en une, basculez dessus, committez, puis revenez sur main : observez quel pointeur avance, et lequel reste en place.

📌 À retenir

  • git branch crée un pointeur, git switch s'y déplace ; git switch -c fait les deux.
  • Un commit n'avance que la branche courante (celle que HEAD désigne).
  • Deux branches qui avancent séparément divergent : l'historique devient un graphe.
