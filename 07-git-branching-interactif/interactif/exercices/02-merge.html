2. Merge : fusionner deux historiques

main et feature ont divergé depuis C2. Intégrez la fonctionnalité dans main avec une fusion à trois points, puis voyez ce qu'est un fast-forward.

📌 À retenir

  • Le commit de fusion a deux parents ; aucun commit existant n'est modifié.
  • git merge fusionne la branche nommée dans la branche courante : placez-vous d'abord sur la branche qui doit recevoir.
  • Si la branche courante est un ancêtre de l'autre, Git avance simplement le pointeur : c'est le fast-forward.
