4. Cherry-pick : prélever des commits précis

La branche experience contient du travail inachevé (C3) mais aussi un correctif de sécurité (C4) et de la documentation (C5). Récupérez uniquement ces deux derniers dans main.

📌 À retenir

  • git cherry-pick copie un commit sur la branche courante : le nouveau commit a un autre identifiant (C4').
  • On peut en prélever plusieurs : git cherry-pick C4 C5 (l'ordre compte).
  • Cas typique : rétroporter un correctif vers une branche de maintenance.
