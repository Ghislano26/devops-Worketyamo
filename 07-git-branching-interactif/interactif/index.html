🌿 Git en images : exercices interactifs

Tapez de vraies commandes Git (fictives) et regardez le graphe des commits évoluer avec animation : un cercle apparaît pour chaque commit, une flèche se dessine vers son parent, les étiquettes de branches glissent d'un commit à l'autre. Inspiré de Learn Git Branching, en plus simple et sans aucune dépendance.

Les exercices

  • 1. Branches de base Créer une branche, basculer, committer, diverger. ✅ Réussi
  • 2. Merge Fusion à trois points puis fast-forward. ✅ Réussi
  • 3. Rebase Rejouer des commits, obtenir un historique linéaire. ✅ Réussi
  • 4. Cherry-pick Prélever des commits précis sur une autre branche. ✅ Réussi

Démos animées

Chaque exercice possède un mode démo qui rejoue la solution en boucle : un bon moyen de voir le graphe évoluer avant de pratiquer.

  • Démo : branches de base
  • Démo : merge
  • Démo : rebase
  • Démo : cherry-pick

Comment lire le graphe ?

  • Un cercle est un commit (C1, C2…) ; la flèche va du commit vers son parent.
  • Un rectangle coloré est une branche : un simple pointeur sur un commit. HEAD → main indique la branche courante.
  • Un cercle en pointillés est un commit orphelin : plus aucune branche ne l'atteint (après un rebase ou un reset --hard), mais il existe encore.
  • Un commit avec une apostrophe (C4') est une copie créée par un rebase ou un cherry-pick : même contenu, autre empreinte.
  • Une flèche violette relie un commit de fusion à son second parent.

Tapez help dans la console d'un exercice pour la liste des commandes.
