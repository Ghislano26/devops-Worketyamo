# Liens utiles

Sélection de références fiables, organisées par thème. Les ressources ci-dessous sont en majorité en anglais : c'est
la réalité du métier. Entraînez-vous à lire la documentation officielle.

> 💡 **Conseil** : en cas de blocage, l'ordre à respecter est : `man` / `--help` → documentation officielle → recherche ciblée avec le **message d'erreur exact** → forums.
